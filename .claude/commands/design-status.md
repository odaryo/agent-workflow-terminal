`docs/architecture.md` から「$ARGUMENTS」に関する記述を探し、次を報告してください。

1. 該当する章・節番号と見出し
2. その項目のステータス: **確定** / **現在の推奨** / **未確定** / **対象外・不採用** のいずれか
3. 確定でない場合、何が決まれば確定になるか(PoC Gate 待ちなら該当Gate番号)
4. 関連する未確定事項(§25 / §31)があれば列挙

ステータスが「確定」でない項目を実装・変更する場合は、先にユーザーへ確認することを推奨として添えてください。推測でステータスを補完しないでください。
